### Beskrivelse

```text
A Claude Code skill that forces a fixed minimalism ladder (reuse existing code, then stdlib, then native platform features, then an already-installed dependency, then a one-liner) before any coding task, and bans speculative abstractions such as single-use interfaces or unused config. Ships three intensity levels (lite, full, ultra). Skip it if you want an agent that defaults to defensive, extensible-by-design code rather than the smallest working diff.
```

### Beskrivelse (dansk)

```text
Erstatter ad hoc-vurderinger af overengineering med en fast tjekliste: genbrug af eksisterende kode, standardbiblioteket, indbyggede platformfunktioner og allerede installerede afhængigheder, før noget nyt eller et abstraktionslag overvejes. Skal undgås af hold, der vil have kode designet til fremtidig udvidelse frem for den mindste løsning, der virker lige nu. Skillen ligger lokalt i dette repositories egen agent-værktøjskasse (.agents/skills/ponytail) og styrer Claude Code's adfærd på enhver kodeopgave: skrivning, refaktorering, fejlretning og valg af biblioteker. Den har tre niveauer (lite, full, ultra) og forbyder ubedte abstraktioner som enkeltstående interfaces og konfiguration for værdier, der aldrig ændrer sig. Fejlrettelser skal ramme den fælles rodfunktion for alle kaldere, ikke det enkelte kaldested.
```
