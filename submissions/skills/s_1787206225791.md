### Beskrivelse

```text
Headless Search Console admin for four named properties (landsvig.com, aiauto.dk, koalafilm.dk, vibetrends.dk). Uses the Search Console API for sitemap status, coverage/indexing, URL inspection, and query/CTR trends, falling back to narrow browser automation only for the manual actions/security issues panel, which has no API. The script validates against the four known properties and refuses any other domain without a code change. Requires an OAuth token and a dedicated Python venv, not a plug-and-play tool for arbitrary GSC accounts.
```

### Beskrivelse (dansk)

```text
Erstatter manuel gennemgang af Google Search Console med en headless Python-klient, der taler direkte med Search Console API'et for fire navngivne domæner: landsvig.com, aiauto.dk, koalafilm.dk og vibetrends.dk. Håndterer sitemap-status, coverage- og indekseringsfejl, URL-inspektion samt query- og CTR-trends uden browser. Manual actions og security issues har intet API og tjekkes derfor stadig via browser. Scriptet validerer domænet mod de fire kendte ejendomme og afviser alt andet, så det ikke bruges på nye sites uden kodeændring. Kræver et OAuth-token og en dedikeret Python-venv, og er derfor ikke en plug and play løsning til andres GSC-konti.
```
