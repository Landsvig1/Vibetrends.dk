### Beskrivelse

```text
gsc-admin replaces manual GSC browsing with a headless API client for four pre-verified properties (landsvig.com, aiauto.dk, koalafilm.dk, vibetrends.dk): sitemap status, coverage/indexing, URL inspection, query/CTR trends. Only the manual actions/security panel runs in a browser (no API for it). Rejects any URL outside those four, so it's not a general-purpose GSC tool. Requires an existing OAuth token and a dedicated Python venv.
```

### Beskrivelse (dansk)

```text
gsc-admin erstatter manuel klik-igennem i Google Search Console med en headless API-klient til fire navngivne, allerede verificerede ejendomme (landsvig.com, aiauto.dk, koalafilm.dk, vibetrends.dk). Skillen bruger Search Console API'et til sitemap-status, dækning/indeksering, URL-inspektion og forespørgsels- og CTR-data, kørt via en dedikeret Python-venv med OAuth-token. Kun ét trin foregår i browseren: panelet for manuelle handlinger og sikkerhedsproblemer, fordi Google ikke tilbyder noget API til det. Scriptet validerer mod de fire kendte ejendomme og afviser andre URL'er, så det er ikke en generel GSC-skill til vilkårlige domæner. Kræver et eksisterende OAuth-token og en opsat venv, uden det giver skillen ingen værdi.
```
