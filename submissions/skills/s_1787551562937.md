### Beskrivelse

```text
Zero-to-live deployment skill built for Kasper's own Hermes agent setup: given a Simply.com domain and a one-line idea, it creates a private GitHub repo, scaffolds a Next.js app with a GDPR privacy page and security headers, and deploys via Vercel. Requires a repo-scope GITHUB_TOKEN, a VERCEL_TOKEN, and an OAuth-connected Simply.com MCP server, plus a SUPABASE_ACCESS_TOKEN if the idea needs Supabase. Skip it without a Simply.com-registered domain or without willingness to grant these tokens to an autonomous skill.
```
