### Beskrivelse

```text
Shells out to the real Claude Code CLI via a bundled script, authenticated with a long lived OAuth token from 'claude setup-token' so calls bill against a Pro or Max subscription instead of a metered API key. Runs the CLI with --dangerously-skip-permissions, so every escalated call has no per-tool permission gate. Refuses to run if ANTHROPIC_API_KEY is set. Skip it without that token already provisioned.
```

### Beskrivelse (dansk)

```text
Skillen kræver et allerede oprettet OAuth-token fra 'claude setup-token' og kører selve Claude Code CLI'en med flaget '--dangerously-skip-permissions', så alle eskalerede kald kører uden tilladelsestjek af værktøjer. Den sender kodeopgaver, fejlsøgning og faktatjek videre til en rigtig Claude Code-session, betalt via et Pro/Max-abonnement i stedet for et målt API-kald. Scriptet afviser kørslen, hvis 'ANTHROPIC_API_KEY' er sat i miljøet, for at undgå at regningen skifter til API-takst uden varsel. Spring den over, hvis du ikke har et langtidsholdbart token sat op, eller ikke vil køre Claude Code helt uden tilladelsestjek.
```
