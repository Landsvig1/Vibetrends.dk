### Beskrivelse

```text
Rejseplanen skill for Clawdbot/MoltBot that queries Danish public transport (S-tog, regional trains, buses) for departures, arrivals, trip planning, and station search. Instead of using Rejseplanen's official key-gated REST API, it connects directly to the internal HAFAS mgate endpoint used by Rejseplanen's own web app, reusing that app's hardcoded auth token and a fixed fallback IP. No user API key is required, but the integration is unofficial and can break without notice if Rejseplanen rotates the token or changes the endpoint. Stdlib-only Python 3.10+, no external dependencies. Skip this if you need a supported, versioned integration.
```

### Beskrivelse (dansk)

```text
Denne skill springer Rejseplanens officielle, nøglekrævende REST-API over og taler i stedet direkte med det interne HAFAS mgate-endpoint, som Rejseplanens egen webapp bruger. Den genbruger webappens hardkodede auth-token og en fast fallback-IP. Det betyder ingen API-nøgle ved opsætning, men integrationen er uofficiel og går i stykker uden varsel, hvis Rejseplanen roterer tokenet eller ændrer endpointet. Skillen dækker afgange, ankomster, rejseplanlægning og stationssøgning for tog og busser, med fuzzy-matching af stationsnavne og JSON-output til automatisering. Bygget i ren Python 3.10+ uden eksterne afhængigheder. Spring den over, hvis du skal bruge en understøttet, versioneret integration.
```
