### Beskrivelse

```text
Daily triage skill for coding-bot PRs (Jules/Bolt/Sentinel) across three of Kasper's own repos. Identifies bot PRs by title prefix or branch name, not author, since the bot commits under his own GitHub identity. Merges safe tiny diffs, runs full review on larger ones, escalates or rejects bloat. Requires authenticated gh CLI with merge/close rights, git worktree support, and each repo's npm/pnpm toolchain. Not portable without rewrites.
```

### Beskrivelse (dansk)

```text
Kræver en autentificeret gh CLI med merge- og luk-rettigheder på tre navngivne repositories, git worktree-understøttelse og hvert projekts eget værktøjskæde (npm eller pnpm) installeret lokalt. Skillet er bygget til Kaspers egen bot-triage på tværs af Koalafilm, Vibetrends.dk og AiAuto, og kan ikke sættes op andre steder uden at omskrive repo-navne og branch-mønstre. Bot-PR'er kendes på titel-præfiks og branch-navn, ikke på forfatterfeltet, fordi boten committer under Kaspers egen GitHub-konto. Kun tomme, sikre ændringer merges automatisk, resten sendes gennem fuld code review eller eskaleres, uden at stole på botens egne benchmark-påstande i PR-teksten.
```
