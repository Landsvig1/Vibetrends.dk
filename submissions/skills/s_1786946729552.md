### Beskrivelse

```text
Zero-to-live deployment skill for domains already registered at Simply.com: scaffolds a private GitHub repo, deploys to Vercel, configures DNS via the Simply.com MCP, and conditionally provisions Vercel Postgres or Supabase based on the idea description. Requires a GitHub PAT (repo scope), a Vercel token, and a pre-owned Simply.com domain; skip it if you lack a Simply.com domain and matching API tokens.
```

### Beskrivelse (dansk)

```text
Erstatter den manuelle rutine med at oprette GitHub-repo, sætte Vercel op og pege DNS hos Simply.com for hvert nyt domæne, du selv ejer. Kræver domænet registreret hos Simply.com på forhånd samt gyldige tokens til GitHub (repo-scope) og Vercel. Simply.com MCP'en (OAuth 2.1) står for domæneopslag og DNS-poster. Skillen klassificerer selv databasebehovet ud fra idébeskrivelsen og opretter kun Vercel Postgres eller Supabase, når opgaven reelt kræver det, hvilket kræver en separat Supabase-adgangstoken. Byggere uden eget domæne hos Simply.com eller uden GitHub- og Vercel-konti bør springe den over.
```
