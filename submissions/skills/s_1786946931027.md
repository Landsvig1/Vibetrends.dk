### Beskrivelse

```text
Daily PR triage skill for Kasper's own coding-bot pipeline. Requires an authenticated gh CLI with merge and close permissions on every target repo, git worktree support, and each repo's local toolchain (npm or pnpm) for pre-merge verification. Classifies bot PRs by title prefix or branch-name pattern, since author/is_bot is unreliable when the bot shares the owner's GitHub identity. Merges trivial safe changes after a light diff read, routes larger or riskier ones through a full code-review-and-fix cycle, and rejects unwarranted complexity as bloat. Not a read-only reviewer: skip it unless you accept granting an agent autonomous merge authority on your repos.
```

### Beskrivelse (dansk)

```text
Kræver en autentificeret gh CLI med ret til at merge og lukke pull requests i alle målrepositories, git med worktree-understøttelse og hvert repos eget værktøjssæt (npm eller pnpm) til verifikation før merge. Skillet styrer den daglige gennemgang af Kaspers kodebots (Jules, Bolt, Sentinel) på tværs af tre repositories. Botten bruger Kaspers egen GitHub-konto, så author og is_bot ikke kan skelne bot fra menneske, bot-PR'er identificeres derfor på titelpræfiks eller branch-navn. Trivielle, sikre ændringer merges efter en kort diff. Større eller risikable ændringer gennemgår en fuld code-review med betinget autofix og merge. Uberettiget kompleksitet afvises som bloat. Botten citeres aldrig som bevis for egne påstande. Skillet har fuld adgang til at merge og lukke, spring det over uden vilje til at give en agent selvstændig mergeret.
```
