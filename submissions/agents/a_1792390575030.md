### Beskrivelse

```text
MCP server and CLI for the e-conomic REST API. Requires an active e-conomic subscription plus an app secret token and agreement grant token; there is no demo mode without a real bookkeeping account. Community package by available-dev, not an official Visma release. Exposes a generic request tool for full API coverage, schema-driven endpoint discovery, and typed convenience tools. Version 0.3.0, early-stage.
```

Use when the user needs to read or write e-conomic bookkeeping data (invoices, customers, chart of accounts, journal entries) through the e-conomic REST API. Requires an e-conomic agreement with a valid app secret token and agreement grant token set as credentials; without them, calls fail.
