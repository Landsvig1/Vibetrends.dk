### Beskrivelse

```text
MCP server for Danish CVR company-registry lookups, built on cvrapi.dk's free public proxy rather than Virk's own official API. At v0.1.0 with no linked source repository, it is an early single-maintainer release: fine for casual lookups in an agent workflow, but skip it for production or high-volume use and reach for Virk's official CVR API instead.
```
