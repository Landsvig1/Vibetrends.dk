### Beskrivelse

```text
Local MCP server for Billy bookkeeping (Danish accounting SaaS). Still at v0.2.1, pre-1.0, so it should not run unattended bookkeeping tasks yet. Retrieves receipts with provenance, proposes bank reconciliation, and queues all writes for review before they hit the ledger. Requires a Billy account with API access.
```

### Beskrivelse (dansk)

Lokal MCP-server til Billys bogholderi. Pakken er stadig på version 0.2.1, altså før 1.0, så den bør ikke sættes til at køre automatisk bogføring uden tilsyn.
