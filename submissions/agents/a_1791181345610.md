### Beskrivelse

```text
Self-hosted MCP server exposing 73 Visma e-conomic API tools (customers, invoices, suppliers, vouchers, accounting) over FastMCP/HTTP. Requires your own hosting (Railway) and an e-conomic developer agreement for API tokens; there is no hosted SaaS version. Ships with Google/Microsoft OAuth login plus an allowlist, email/password login, read-only mode, per-call audit logging, a Danish setup guide, and seven Claude Code skills for e-conomic workflows.
```
