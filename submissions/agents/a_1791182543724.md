### Beskrivelse

```text
MCP server that exposes Danish companies' published annual reports from the Danish Business Authority (Erhvervsstyrelsen) open data to MCP clients like Claude. Parses the underlying XBRL/XML filing format via fast-xml-parser rather than a pre-cleaned JSON feed. Built for agents that need structured financial data on Danish companies without manual lookup on regnskaber.virk.dk.
```

### Beskrivelse (dansk)

```text
Erstatter manuelt opslag af årsrapporter på regnskaber.virk.dk med en MCP-server, der henter selskabers regnskabsdata fra Erhvervsstyrelsens åbne data. Ifølge pakkens afhængighed til fast-xml-parser parses det underliggende XBRL/XML-format fra regnskaberne, ikke en færdigrenset JSON-feed. Bygget til MCP-klienter som Claude, der skal slå danske selskabers regnskabstal op programmatisk i stedet for via browseren.
```

Use this MCP server to look up Danish companies' published annual reports (årsrapporter) from Erhvervsstyrelsen's open data. Query by CVR number. Returns structured financial filing data parsed from the underlying XBRL/XML source.
