### Beskrivelse

```text
CLI wrapper for DAWA (Danmarks Adressers Web API). Published in 2015 and untouched since: none of its three dependencies (endpoint, ndjsonpoint, util-extend) has shipped a release since 2015-2016 either. Fine for a quick, throwaway address lookup script. Skip it if you need maintained code, typed APIs, or assurance against future Node.js breakage; call the DAWA REST API directly instead for anything production-facing.
```

### Beskrivelse (dansk)

```text
denmark-dawa er en Node.js-klient til DAWA (Danmarks Adressers Web API), men pakken har ikke fået en opdatering siden 2015, og afhængighederne endpoint, ndjsonpoint og util-extend har heller ikke fået nye versioner siden 2015 til 2016. Brug den kun til hurtige, engangsopslag på adresser. Skal du bruge vedligeholdt kode med typer, så kald DAWA's REST-API direkte i stedet. Kræver Node.js og installeres globalt via npm.
```
