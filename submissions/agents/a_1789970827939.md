### Beskrivelse

```text
MCP server for DanskCvrApi that gives AI agents tools to look up Danish company data, financials, industries and statistics from the CVR register. Requires a DanskCvrApi account and API key since it wraps their commercial API layer, not the free public CVR/Virk data feed directly.
```

### Beskrivelse (dansk)

```text
Kræver en konto og API-nøgle hos DanskCvrApi, da serveren kalder deres kommercielle API og ikke Erhvervsstyrelsens gratis CVR/Virk-data direkte. Giver MCP-klienter som Claude Desktop og Cursor værktøjer til opslag på danske virksomheder, regnskabstal, branchekoder og statistik. Afhængighederne er kun MCP SDK og zod, så al opslag går igennem DanskCvrApis eget REST-endpoint. Spring den over hvis du kun har brug for gratis CVR-opslag.
```

### System-prompt

```text
Look up Danish company data, financials, industries and statistics from the CVR register via the DanskCvrApi service. Requires a DANSKCVRAPI_API_KEY environment variable tied to a valid DanskCvrApi account; this calls a third-party commercial API, not Erhvervsstyrelsen's free CVR/Virk feed directly.
```
