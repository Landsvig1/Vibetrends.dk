### Beskrivelse

```text
TypeScript client for getaddress.dk, a paid third-party service that mirrors DAWA's address API (autocomplete, adresser, adgangsadresser, reverse geocoding, vejnavne, postnumre), plus CVR company lookup and batch address cleaning not in the official free DAWA. Requires a getaddress.dk API key (from 49 DKK/month after a 30-day trial). Skip it for plain address lookups and call DAWA directly.
```
