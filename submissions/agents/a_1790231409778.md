### Beskrivelse

```text
DanNet's MCP server is not an installable npm or pip package: it is a hosted connector at https://wordnet.dk/mcp, added to Claude as a custom connector. It exposes the Danish WordNet, an RDF knowledge graph of words, meanings and relations built with Apache Jena, so an LLM can query Danish synonyms, hyponyms and sense relations instead of hand-written SPARQL. No offline install path exists; self-hosting means running the full Docker Compose stack (app, MCP server, Caddy) yourself.
```

### Beskrivelse (dansk)

```text
DanNet er ikke en pakke man installerer med npm eller pip, men en fjernforbindelse på https://wordnet.dk/mcp, tilføjet som custom connector i Claude. Serveren giver adgang til det danske WordNet, en semantisk vidensgraf med ord, betydninger og relationer i RDF. En LLM kan slå danske synonymer og betydningsrelationer op uden manuel SPARQL. Selvhosting kræver egen Docker Compose opsætning, der findes ingen installationskommando.
```
