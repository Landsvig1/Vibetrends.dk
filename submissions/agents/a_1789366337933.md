### Beskrivelse

```text
MCP server that connects Claude and other AI assistants to Billy.dk, the Danish bookkeeping platform. Exposes invoices, bills, journal entries, trial balance, and bank reconciliation as MCP tools. Requires a Billy.dk account and API credentials to function. Write operations are gated behind human approval, per the package's own description. Grounded via npm registry metadata (v0.3.2) only, not installed or run.
```

### Beskrivelse (dansk)

```text
Kræver en Billy.dk-konto og API-nøgle for at fungere; uden den har billy-mcp ingen brugbare værktøjer. Serveren forbinder Claude og andre AI-assistenter til Billy.dks bogføring: fakturaer, bilag, bogføringsposter, saldobalance og bankafstemning som MCP-værktøjer. Skriveoperationer kræver ifølge pakkens egen beskrivelse manuel godkendelse, hvilket ikke er efterprøvet her. E-conomic- og Dinero-brugere kan springe den over.
```
