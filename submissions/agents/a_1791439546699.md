### Beskrivelse

```text
Replaces separate Stripe and Vipps MobilePay integration code with one PaymentProvider interface: create, capture, refund, set up and charge recurring agreements, verify webhooks. Requires a self-managed Postgres database for the provider-neutral agreements and charges store; no hosted dashboard included. Holds no card data itself. Early-stage (v0.4.0). Skip if you only need one provider with a managed billing console.
```
