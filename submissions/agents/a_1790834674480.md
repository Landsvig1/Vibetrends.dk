### Beskrivelse

```text
MCP server wrapping Energi Data Service, Energinet's public open data API for Danish electricity prices, production and consumption, as MCP tool calls. Requires no API key, since the underlying data is public. Version 0.1.2, pre-1.0, so the tool interface may still change. Skip it if you need paid or non-public energy data, or a stable 1.0 release.
```

### Beskrivelse (dansk)

```text
Kræver ingen API-nøgle, fordi det er en wrapper om Energi Data Service, Energinets offentlige API for danske elpriser, produktion og forbrug, hvor data allerede er gratis og offentligt tilgængelige uden login. Serveren er på version 0.1.2, så ændringer i værktøjernes grænseflade må forventes. Spring den over, hvis du har brug for data der ikke findes hos Energi Data Service, eller en stabil 1.0-udgave.
```

### System-prompt

```text
Du har adgang til en MCP-server for Energi Data Service (Energinet). Brug den til opslag på danske elpriser, elproduktion og elforbrug fra det offentlige API. Serveren er på version 0.1.2, så behandl svarformatet som foranderligt. Brug den ikke til prognoser, rådgivning eller handel, kun til opslag på rå, offentlige data.
```
