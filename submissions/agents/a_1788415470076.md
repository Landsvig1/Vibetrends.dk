### Beskrivelse

```text
Official reference CLI for DAWA's replication API (Danmarks Adressers Web API), letting a client pull incremental deltas of Danish address, road and postal-code data instead of re-downloading the full dataset. Depends on the deprecated request/request-promise libraries (unmaintained since Feb 2020) plus underscore and urijs; audit dependencies before installing under an SCA policy.
```

### Beskrivelse (dansk)

```text
Denne CLI afhænger af de forældede HTTP-biblioteker request og request-promise (opgivet af deres vedligeholdere i februar 2020) samt af underscore og urijs frem for vedligeholdte alternativer. Den er SDFI's officielle referenceklient til DAWA's replikerings-API og henter kun ændringer i adresser, veje og postnumre siden sidste synkronisering uden at hele datasættet skal downloades igen. Gennemgå afhængighederne, før klienten bruges i produktion.
```
