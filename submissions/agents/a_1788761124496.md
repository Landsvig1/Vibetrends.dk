### Beskrivelse

```text
MCP server with 33 tools for Danish company data (CVR) via the third-party service FirmaAPI.dk, not the free official Erhvervsstyrelsen/Virk API. Covers company lookup, 30+ filter search, batch lookup of up to 500 CVR numbers, financial health scoring, ownership trees, board overlap and KYC screening of officers. Requires a FirmaAPI.dk account and API key; lookup and search are free, person, ownership and KYC tools need a paid Basis/Standard/Pro plan.
```
