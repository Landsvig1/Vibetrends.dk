### Beskrivelse

```text
Node-RED node that pulls messages, weekly plans, and calendar events from Aula, the Danish school communication platform. Aula has no public third-party API, so the node relies on the webhead package to handle login and session, likely via a headless browser. That means real UNI-Login or MitID credentials must be stored in your Node-RED flow. Unofficial, not affiliated with Aula or KMD. Skip it if you are unwilling to store a child's school login inside an automation server.
```
