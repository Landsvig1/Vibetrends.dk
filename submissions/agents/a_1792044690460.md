### Beskrivelse

```text
Official CLI for Lead Strategist's commercial API, wrapping Denmark's CVR company register and annual-report financials (about 948,000 companies, 460,000 with financials). Requires a paid, credit-metered API key after a 14-day or 2,000-credit trial; skip it if you only need basic CVR lookups, which are free via Virk. Commands cover search by industry, size, and revenue, plus financials.
```
