### Beskrivelse

```text
Python CLI ("rejs") for Danish public transport via Rejseplanen's Journey Planner API 2.0: departures, station-to-station and address-to-address trip planning, nearby-stop lookup, and saved routes. Requires a personal Rejseplanen Labs API key; not published on PyPI, so install is git clone plus uv, not a plain pip install.
```

### Beskrivelse (dansk)

```text
Kræver en personlig API-nøgle fra Rejseplanen Labs, uden den virker værktøjet slet ikke, og pakken er ikke udgivet på PyPI, så installation foregår via git clone og uv, ikke en almindelig pip install. CLI'et (kommandoen rejs) viser afgangstavler, planlægger rejser mellem stationer eller adresser, finder nærmeste stoppested og gemmer faste ruter. Nøglen ligger i systemets keyring eller en lokal .env-fil.
```

### System-prompt

```text
CLI for Danish public transport, wraps Rejseplanen Journey Planner API 2.0. Commands: rejs departures <station>, rejs search <query>, rejs trip <from> <to>, rejs trip-from-address <from> <to>, rejs nearby <address>, rejs save/route <name>, rejs config set-api-key <key>. Requires a Rejseplanen Labs API key (set once via config or .env) before any command returns data.
```
