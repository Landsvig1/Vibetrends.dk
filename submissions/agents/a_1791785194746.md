### Beskrivelse

```text
naviair-charts resolves AIP and VFR Flight Guide chart names from NAVIAIR (aim.naviair.dk) to the PDF URL that is valid right now. NAVIAIR re-issues every chart under a new random folder path on each 28-day AIRAC cycle, so saved links break. The package queries NAVIAIR's own API instead of scraping. Requires Node.js 20.10+, server-side only (no CORS for browsers).
```

### Beskrivelse (dansk)

```text
naviair-charts erstatter manuel genfinding af PDF-links fra aim.naviair.dk, som NAVIAIR lægger i en ny, tilfældig mappe for hvert AIRAC-cyklus (hver 28. dag), så gemte links holder op med at virke. Pakken (npm, med CLI) slår chartet op via NAVIAIR's eget API ud fra ICAO-kode eller titel og returnerer den aktuelt gyldige URL. Kører kun server-side, da aim.naviair.dk ikke sender CORS-headers til browsere. Kræver Node.js 20.10 eller nyere.
```
